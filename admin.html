Email members from hello@forecut.in (Zoho Mail)

Everyone goes in Bcc, so members never see each other's addresses. Lists over 50 open in batches of 50.
One-time setup so this opens Zoho: sign in at mail.zoho.in → Settings → System → Mail To Handlers → Enable Mail To Handler → Allow. If the message does not fill in, use the Copy buttons and paste into a new Zoho email.

Bring in everyone who has signed up

  1. Open Firebase console → Authentication → Users.
  2. At the bottom of the list, set Rows per page to the largest number so everyone is on one page.
  3. Click anywhere on the list, press Ctrl + A (Mac: Cmd + A), then Ctrl + C (Mac: Cmd + C).
  4. Paste below with Ctrl + V and press Check. Extra text from the page is ignored.
